입문

창업 기초

창업이 처음인 분이 아이디어를 사업 모델로 바꾸는 과정입니다.

대상대학생, 예비 창업자구성6강
  1. 창업, 무엇부터 할까창업의 흐름과 준비 순서
  2. 아이템 발굴생활 속 문제에서 아이디어 찾기
  3. 고객과 문제 정의누구의 어떤 문제를 풀까
  4. 시장 조사경쟁 상품·가격·트렌드 분석
  5. 비즈니스 모델 캔버스한 장으로 그리는 사업 구조
  6. 작게 시작하기MVP로 빠르게 검증하는 법
기본

사업계획서 · 지원사업

정부·지자체 창업 지원사업에 도전할 수 있도록 계획서와 발표를 준비합니다.

대상예비·초기 창업자구성5강
  1. 창업 지원사업 한눈에 보기종류, 일정, 나에게 맞는 사업 찾기
  2. 사업계획서 구조 잡기심사위원이 보는 핵심 항목
  3. 시장·경쟁 분석 쓰기근거 있는 숫자로 설득하기
  4. 매출·자금 계획초보자를 위한 재무 계획
  5. 발표와 피칭짧고 분명하게 전달하는 법
기본

브랜딩 · SNS 마케팅

작은 가게와 1인 브랜드가 고객에게 기억되는 방법을 배웁니다.

대상창업자, 소상공인구성6강
  1. 브랜드 콘셉트 잡기우리만의 이야기와 차별점
  2. 네이밍과 디자인 방향이름·로고·컬러 정하기
  3. 인스타그램 운영피드 기획과 꾸준한 발행
  4. 블로그 마케팅검색에 걸리는 글쓰기
  5. 사진·숏폼 콘텐츠스마트폰으로 찍고 편집하기
  6. 리뷰와 단골 관리후기가 쌓이는 구조 만들기
실무

온라인 쇼핑몰 실무

상품 소싱부터 스토어 개설, 판매, 광고, 운영까지 쇼핑몰 창업의 전 과정을 실습합니다.

대상온라인 판매 입문자구성8강
  1. 온라인 판매 시작하기채널별 특징과 판매 구조
  2. 상품 소싱도매·제조·위탁 판매 이해
  3. 스마트스토어 개설가입부터 기본 설정까지
  4. 상품 등록과 검색 최적화잘 보이는 상품명·태그
  5. 상세페이지 기획사고 싶게 만드는 구성
  6. 광고 운영 기초검색 광고와 예산 관리
  7. 주문·배송·CS운영 실무와 정산
  8. 자사몰로 확장하기채널 확장과 재구매 전략

대상창업자, 쇼핑몰 운영자구성4강

  2. 상세페이지·광고 문구AI로 카피 쓰고 다듬기
  3. 이미지·콘텐츠 제작상품 사진·SNS 이미지 만들기
