## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 메인(홈) 페이지 |
| `consulting.html` | 창업 컨설팅 서브페이지 |
| `lecture.html` | 강의 서브페이지 (6개 과정 커리큘럼) |
| `shop.html` | 쇼핑몰 창업 서브페이지 (3단계 12회차 커리큘럼) |
| `smallbiz.html` | 소상공인 지원 서브페이지 (3단계 10회차 프로그램) |
| `style.css` | 모든 페이지 공통 디자인 |

## 페이지 연결 구조

```
index.html
├─ 상단 메뉴: 창업 컨설팅 · 강의 · 쇼핑몰 창업 · 소상공인 지원 · (상담 문의 → #contact)
├─ 히어로 키커 문구의 각 서비스명 → 서브페이지
├─ 서비스 카드 제목 + "자세히 보기 / 커리큘럼 보기" 버튼 → 서브페이지
└─ 문의(#contact): 카카오톡 QR코드 + 오픈채팅 바로가기 버튼 + 이메일·블로그 링크

서브페이지 (consulting / lecture / shop / smallbiz)
├─ 상단 메뉴: 4개 서브페이지 서로 연결 (현재 페이지는 밑줄 표시) + "← 홈으로"(index.html)
├─ 로고 → index.html
└─ 하단 CTA: "OO 문의하기" → 카카오톡 오픈채팅 / "QR코드 보기" → index.html#contact
```

> 모바일 화면(폭 900px 이하)에서는 상단 메뉴 링크가 숨겨지고, 서비스 카드 버튼과 "← 홈으로"로 이동합니다.

## 페이지별 내용

### index.html (홈)
1. 히어로: 창업나침반 타이틀, 소개 문구, "상담 신청" 버튼
2. SERVICES: 창업 컨설팅 / 강의 / 쇼핑몰 창업 / 소상공인 지원 카드
3. ROADMAP: 상담 → 진단 → 계획 → 실행 → 성장 (구불구불한 길 일러스트)
4. FOR YOU: 예비 창업자 / 온라인 판매 입문자 / 소상공인 사장님
5. CONTACT: 카카오톡 QR코드, 오픈채팅 버튼, 카카오톡·이메일·블로그 링크

### consulting.html (창업 컨설팅)
- 하는 일: 아이템 점검·시장 분석 / 사업계획서 코칭 / 창업 지원사업 준비 / 창업 초기 세팅
- 진행: 문의 → 첫 상담 → 맞춤 진단 → 실행 코칭
- 자주 묻는 질문 3개

### lecture.html (강의)
| 과정 | 수준 | 회차 | 주요 내용 |
|---|---|---|---|
| 창업 기초 | 입문 | 6강 | 아이템 발굴, 고객·문제 정의, 시장 조사, 비즈니스 모델 캔버스, MVP |
| 사업계획서 · 지원사업 | 기본 | 5강 | 지원사업 이해, 계획서 구조, 시장 분석, 재무 계획, 피칭 |
| 브랜딩 · SNS 마케팅 | 기본 | 6강 | 브랜드 콘셉트, 네이밍, 인스타그램, 블로그, 숏폼, 리뷰 관리 |
| 온라인 쇼핑몰 실무 | 실무 | 8강 | 소싱, 스마트스토어 개설, 검색 최적화, 상세페이지, 광고, CS, 자사몰 |
| AI 활용 창업 | 심화 | 4강 | AI 기획, 카피, 이미지 제작, 업무 자동화 |
| 소상공인 디지털 전환 | 맞춤 | 4강 | 플레이스 관리, 리뷰·예약, 온라인 판로, 지원 제도 |

- 운영 방식: 특강(1회 2~3시간) / 단기 과정(4~8회) / 정규 강의(한 학기)
- 대상: 대학 / 기관·지자체 / 소상공인

### shop.html (쇼핑몰 창업)
- **STEP 1 준비:** 온라인 시장 이해 · 팔릴 상품 찾기 · 상품 소싱 · 창업 행정 준비
- **STEP 2 오픈:** 스마트스토어 개설 · 상품 등록·검색 최적화 · 상품 사진 촬영 · 상세페이지 제작
- **STEP 3 성장:** 광고 운영 기초 · SNS·체험단 홍보 · 주문·배송·CS · 데이터 보고 키우기

### smallbiz.html (소상공인 지원)
- **STEP 1 진단:** 매장 현황 점검 · 상권·고객 분석 · 온라인 노출 점검
- **STEP 2 개선:** 지도·플레이스 정비 · 리뷰·단골 관리 · SNS 홍보 시작 · 메뉴·상품 구성
- **STEP 3 확장:** 온라인 판매 시작 · 배달·라이브커머스 · 지원 제도 활용

## 작업 내역

1. 미리보기 시안을 `index.html`로 정리해 저장 (독립 실행되는 HTML 구조로 정리)
2. 창업 컨설팅 서브페이지(`consulting.html`) 제작 및 메뉴·카드 연결
3. 전체 폰트를 둥근 글씨체(Jua + Gowun Dodum)로 변경
4. "대학 강의" → "강의"로 변경, 강의 서브페이지(`lecture.html`) 제작 — 6개 과정 커리큘럼
5. 쇼핑몰 창업(`shop.html`), 소상공인 지원(`smallbiz.html`) 서브페이지 제작 — 컨설팅 페이지와 같은 구성 + 단계별 커리큘럼
6. 서브페이지 상단 메뉴 통일 (4개 서브페이지 상호 연결, 현재 페이지 표시, 홈으로 버튼)
7. 문의를 카카오톡 오픈채팅 QR코드로 연결 (`images/kakao-qr.png`, 각 페이지 문의 버튼)
8. 문의 섹션에 이메일·블로그 추가, 전화번호·SNS 칸 삭제
9. 데스크톱(1280px)·모바일(390px)에서 가로 넘침 없는지, 페이지 간 링크가 동작하는지 확인
10. 전체 디자인 리뉴얼: 공통 style.css 도입
11. 디자인 재변경: 대담한 블랙·오렌지 테마, 새 Pixabay 사진, Pretendard 폰트
